# 三大受控实验详解（校准 · 过滤均衡 · 商家数比较静态）

本文档对应论文 *"When Retrieval Becomes Strategic"* 附录中的三个检索回放（retrieval-replay）实验，按 **实验目的 → 实验设置 → 实验步骤 → 实验结果** 的结构逐一详解。所有数字直接来自仓库 `results/` 下的结果文件（3 种子均值），可复现命令见文末。

---

## 0. 总览：三个实验在论证链中的位置

论文的治理模型把 RAG 毒化建模为商家在"注入成本 ↔ 检索曝光"之间的最优反应问题，核心是一个**曝光形成定律**：

```
q = X / (X + ρ̂)
```

其中 `q ∈ [0,1]` 是对抗内容在检索结果中的曝光份额，`X` 是注入文档占语料的份额，`ρ̂` 是**检索阻力**（domain-level 常数，刻画该域语料把注入文档"挤出"top-10 的能力）。模型在此定律之上推出平台（过滤强度 r）、商家（注入量、商家数 N、收益比 ω）三方的均衡与比较静态。

三个实验分别压住模型的一层假设做受控检验：

| 实验 | 检验对象 | 一句话结论 |
|---|---|---|
| 实验一（E0） | 曝光形成定律本身 + 参数 ρ̂ | 三域 R² ≥ 0.958，定律成立，ρ̂ 成为后续实验的预测参数 |
| 实验二（E1） | 平台侧动作（过滤 r）与闭锁定理 | 过滤按乘法方式压缩曝光；商家重新最优化后均衡可达；按模型给的最小过滤强度 r* 过滤，三域实测曝光全部落到容忍线 q̄=0.3 之下 |
| 实验三（E3） | 供给侧结构（商家数 N、收益比 ω）的比较静态 | 搭便车（人均剂量随 N 下降）、总曝光随 N 与 ω 上升、池子容量构成天然上限，全部与理论一致 |

### 0.1 共同基础设施（三个实验完全一致）

- **数据与检索栈**：三个商品域 `camera` / `ev` / `shoes`，各域由真实商品语料与真实查询构成。检索复现与线上一致：句向量编码 → FAISS 内积检索 → top-10。全程**离线确定性回放，不调用任何 LLM API，纯 CPU 可跑**。
- **注入池**：每域一个对抗注入文档池（camera 176 篇、ev 176 篇、shoes 184 篇），独立于商品语料存放；实验中按配置从中抽取文档并入索引。
- **曝光度量 q**：回放该域全部查询，统计每条查询 top-10 结果中注入文档的占比，再对查询平均。q=0.3 即"平均每页 10 条结果里有 3 条是注入内容"。
- **种子与误差棒**：种子 101 / 202 / 303（控制注入抽样等随机性；编码与检索本身确定性）。全文"误差棒"= 3 种子均值 ± 1 个标准差（ddof=1）。
- **加速**：向量编码结果落盘缓存于 `results/cache/vec_cache.pkl`，重跑实验只需数分钟。
- **关键参数（由 E0 标定）**：

| 域 | ρ̂ | 注入池 \|P\| |
|---|---|---|
| camera | 0.334 | 176 |
| ev | 0.919 | 176 |
| shoes | 0.839 | 184 |

## 1. 实验一（E0）：曝光形成定律的校准

### 1.1 实验目的

1. **验证定律形式**：检验 `q = X/(X+ρ̂)` 是否在真实检索栈上成立——即曝光是否只由注入份额 X 与域阻力 ρ̂ 决定，且呈该饱和形态；
2. **标定 ρ̂**：为每个域拟合出一个检索阻力值，作为实验二、实验三所有理论预测的输入参数；
3. **确认 ρ̂ 的"域常数"地位**：ρ̂ 在后续实验中被当作不随注入策略、语料小扰动变化的常数，这本身需要证据支撑（见 1.4 的两项稳健性检查）。

### 1.2 实验设置

- **域**：camera / ev / shoes 三域独立做，互不混用。
- **注入配置网格**：每域 29 个配置，覆盖单商家/双商家拆分 × 注入剂量从极小（~5 篇）到接近全池，使 X 从 ~0.03 扫到 ~0.9——刻意覆盖定律曲线的饱和段，避免"只测直线段拟合必然好"的质疑。
- **测量点**：29 配置 × 3 种子 = **87 点/域**。
- **拟合对象**：对全部 87 个 `(X, q_measured)` 点做单参数非线性最小二乘，拟合 `q = X/(X+ρ̂)`，报告 R²、MAE、RMSE。
- **无平台干预**：r=0（不过滤）、N 与 ω 不进入本实验——把"定律形式"与"策略行为"解耦，这是它必须排第一的原因。

### 1.3 实验步骤

1. 为每个域构建 FAISS 索引（商品语料全量编码入库）；
2. 对注入配置网格中的每个配置：
   a. 按当前种子从注入池抽取该配置规定数量的文档，加入索引；
   b. 回放该域全部查询，取 top-10；
   c. 统计注入文档在 top-10 中的份额，对查询平均，得到该配置的实测曝光 `q_measured`；
   d. 记录注入份额 `X = 注入篇数 / |P|`；
3. 汇总 87 个点，最小二乘拟合 ρ̂；
4. 输出 `results/e0/e0_{domain}.csv`（逐点明细）与 `results/e0/e0_fit_{domain}.json`（拟合汇总）；
5. 绘制观测-预测散点图 `e0_exposure_fit_{domain}.pdf`（论文附录图）。

### 1.4 实验结果

| 域 | ρ̂ | R² | MAE | RMSE | 点数 |
|---|---|---|---|---|---|
| camera | 0.334 | 0.971 | 0.032 | 0.039 | 87 |
| ev | 0.919 | 0.967 | 0.022 | 0.028 | 87 |
| shoes | 0.839 | 0.958 | 0.023 | 0.031 | 87 |

（论文图上的统计框给出的是"先对种子取平均再拟合"的变体，R² 分别为 0.974 / 0.969 / 0.961，与逐点拟合相差 <3%，结论不变。）

**要点解读**：

- **定律成立**：三个域 R² 均 ≥ 0.958，MAE ≤ 0.032——在覆盖饱和段的 87 个点上，单参数定律解释了绝大部分变异。图上点云紧贴理想线，无明显系统性弯曲。
- **ρ̂ 的排序即"域难度"**：camera（0.334）阻力最小，注入最"便宜"；ev（0.919）阻力最大。这个排序直接预言了后续实验中三域所需过滤强度的巨大差异（camera 需要 r*≈0.80，ev 只需要 r*≈0.45）。
- **ρ̂ 对语料规模近不变（E2 支撑实验）**：把 camera 语料 4 倍扩容/缩容重测，ρ̂ 仅从 0.037 变到 0.053（低 X 段局部估计），且防御效果主要走"稀释"通道（固定注入量下语料缩小反而推高 q 从 0.60 到 0.78）——支持把 ρ̂ 当域级常数处理。
- **种子稳健**：逐点拟合与种子平均拟合差异 <3%，说明测量噪声主要来自注入抽样而非查询回放本身。

## 2. 实验二（E1）：过滤响应与均衡可达性

### 2.1 实验目的

平台侧只有一个动作——过滤强度 r（删除嫌疑文档的比例）。模型对它给出两个独立断言，本实验各验证一个：

1. **乘法性（天真商家场景）**：若商家不针对过滤调整注入量（固定臂），过滤以 η=1−r 乘性进入定律，实测曝光应沿 `q(r) = ηX/(ηX+ρ̂)` 衰减；
2. **均衡可达性与闭锁（策略商家场景）**：若商家会针对过滤重新最优化（策略臂），实测**过滤后**曝光应落在最优反应曲线 `q*(η)` 上；并且按模型给出的最小过滤强度

```
r* = 1 − η*,   η* 由 q*(η*) = q̄ = 0.3 解出
```

实施过滤后，实测曝光应**从上方恰好压到容忍线之下**（闭锁检查）。这同时量化了**策略性溢价**——同样的过滤下，会重新优化的商家比天真商家多拿多少曝光——支撑论文"过滤必须按策略性均衡校准，否则形同虚设"的核心动机。

### 2.2 实验设置

| 项目 | 取值 |
|---|---|
| 商家数 N | 2（对称） |
| 收益比 ω | 1 |
| 容忍线 q̄ | 0.3 |
| ρ̂ | 取 E0 标定值（0.334 / 0.919 / 0.839） |
| r 网格 | {0, 0.2, 0.4, 0.6, 0.8, 0.95} ∪ {r*}（camera r*=0.800，ev 0.448，shoes 0.497），共 7 点 |
| 种子 | 101 / 202 / 303 |

**两臂设计**（同一平台行为下对照）：

- **固定臂（天真商家）**：每商家恒定注入 40 篇、共 80 篇（camera/ev 池 176 → X≈0.455；shoes 池 184 → X≈0.435），**不随 r 变化**。预测曲线：`q̂ = ηX/(ηX+ρ̂)`。
- **策略臂（最优反应商家）**：每一轮先对当前 r 解最优反应曲线
  `ω·η²·(1−q)²·(N−q) = q·ρ̂²` 得到均衡曝光 `q*(η)`，
  再换算每商家剂量 `x*(η) = q*·ρ̂ / (η·N·(1−q*))·|P|` 篇并注入。预测曲线：`q̂ = q*(η)`。

**过滤的统一实现**：对每个已注入文档**独立地**以概率 r 删除（保留概率 1−r），删除后重建索引再回放查询。两臂走同一删除过程；**策略臂的曝光在删除之后测量**——与模型时间线（商家预见过过滤、平台过滤发生在索引之前）一致。这是本实验设计上最关键的一点：策略臂的注入量是"对着过滤器来的"，测的却是过滤后的净曝光。

### 2.3 实验步骤

1. 对 r 网格中的每个值：
   a. **固定臂**：注入 40+40 篇 → 施加 Bernoulli 删除（保留 1−r）→ 重建索引 → 回放查询 → 记录过滤后曝光；
   b. **策略臂**：解 `q*(η)` 与 `x*(η)` → 按剂量注入 → 施加同一删除过程 → 重建索引 → 回放查询 → 记录过滤后曝光；
2. 每个配置重复 3 个种子；
3. 与预测曲线对比，计算各臂平均绝对误差 MAE；
4. **闭锁检查**：在 r = r* 处读策略臂实测曝光，验证 ≤ q̄ = 0.3；
5. **策略性溢价**：逐 r 计算 `策略臂 − 固定臂` 实测差；
6. 输出 `results/e1/e1_{domain}.csv` 与三域面板图 `e1_filtering_panels.pdf`。

7. **无过滤基线**：r=0 时策略均衡曝光 0.81 / 0.55 / 0.58——camera 达容忍线的 2.7 倍。

## 3. 实验三（E3）：商家数与收益比的比较静态

### 3.1 实验目的

供给侧结构参数如何移动战略均衡？模型给出四条可证伪的比较静态，本实验逐一检验：

1. **搭便车（free-riding）**：对称均衡下每商家剂量 `x*(N) = q*(N)·ρ̂/(N·(1−q*(N)))·|P|` 随 N 递减——商家数越多，人人注入越少；
2. **总曝光随 N 上升**：`q*(N)` 随 N 递增——"人多"对攻击方是红利，对平台是坏消息；
3. **收益比效应**：曝光对商家的相对价值 ω 越高，均衡曝光 `q*(ω)` 越高（∂q*/∂ω > 0）；
4. **池子容量截断**：当理论剂量超过商家的子池容量 `|P|/N` 时，注入被截断，实测曝光**饱和在未截断预测之下**——这是模型治理分析中天然阻尼器的直接证据。

治理含义：防捺不能按"单个敌人"定参，必须随商家数量与收益结构重校准——这是论文治理章节需要实验背书的结论。

### 3.2 实验设置

| 项目 | 取值 |
|---|---|
| 商家数 N | {1, 2, 4, 8}（把注入池均分为 N 个**不相交**子池，每商家一个子池） |
| 收益比 ω | 主臂用校准值 ω*；另设扫描臂 ω ∈ {0.5, 1, 2}（N=2） |
| ρ̂ | 取 E0 标定值 |
| 种子 | 101 / 202 / 303 |

**ω* 的校准**（每域一次，使 N=2 的均衡恰为 q*=0.5）：

| 域 | ω* |
|---|---|
| camera | 0.148 |
| ev | 1.126 |
| shoes | 0.939 |

校准的意义：把 ω* 代入最优反应曲线后，**ρ̂ 从曲线中消去**，得到三域共享的理论序列

```
q*(N) = 0.356, 0.500, 0.627, 0.726   （N = 1, 2, 4, 8）
```

即"曝光随 N 上升的**形状**"是域无关预测；而实现它所需的**剂量** `x*(N)` 依赖 ρ̂ 与 |P|，各域不同。于是本实验同时检验两点：形状对不对（三域共享），剂量对不对（各域自己算）。

**两臂设计**：

- **固定剂量臂（equal_m）**：每商家恒定注入 m ∈ {5, 10, 20} 篇，N∈{1,2,4,8} 全组合（每域 12 配置 × 3 种子 = 36 点）。预测：聚合定律 `q̂ = X/(X+ρ̂)`，`X = N·m/|P|`。它验证聚合定律对任意 (N, m) 组合的外推能力。
- **均衡臂（equilibrium_w*）**：每商家按 `x*(N)` 注入（若 `x*(N) > |P|/N` 则截断到子池容量并标记 `capped`）。
- **收益比扫描臂（omega_0.5 / omega_1 / omega_2）**：N=2、r=0，按对应 ω 解 `q*(ω)` 并注入，同样截断标记。

（另有一个成本不对称臂——两个商家注入成本不同——已运行；因论文建模部分未形式化成本不对称，其结论不进入论文，此处仅注明数据存在：`e3_*.csv` 的 `share_lowcost/share_highcost` 列。）

### 3.3 实验步骤

1. 把注入池均分为 N 个子池；
2. 按当前臂计算注入方案：
   a. equal_m：每商家 m 篇；
   b. equilibrium_w*：解 `q*(N)` → `x*(N)` → 若超子池容量则截断并标记；
   c. omega_w：解 `q*(ω)` @ N=2 → 换算剂量 → 截断同上；
3. 注入、回放查询、统计曝光 `q_measured`（3 种子重复）；
4. 与理论对比：记录 `q_pred`（截断点仍与未截断理论对照，以显示饱和差距）；
5. 计算各臂 MAE（截断点不计入未截断 MAE）；
6. 输出 `results/e3/e3_{domain}.csv` 与两张单栏图 `e3_nsweep_column.pdf`、`e3_omega_column.pdf`。

### 3.4 实验结果

**（a）均衡 N 扫描（3 种子均值；q*(N) 为三域共享理论值；† = 截断）**

| N | q*(N) | camera x* / 实测 q | ev x* / 实测 q | shoes x* / 实测 q |
|---|---|---|---|---|
| 1 | 0.356 | 32 / 0.380 | 89 / 0.341 | 85 / 0.339 |
| 2 | 0.500 | 29 / 0.532 | 81 / 0.576 | 77 / 0.571 |
| 4 | 0.627 | 25 / 0.657 | 68† / 0.607 | 65† / 0.641 |
| 8 | 0.726 | 19 / 0.786 | 54† / 0.607 | 51† / 0.641 |

**（b）收益比扫描（N=2，r=0；† = 截断；括号内为理论 q*(ω)）**

| ω | camera 实测（理论） | ev 实测（理论） | shoes 实测（理论） |
|---|---|---|---|
| 0.5 | 0.728（0.666） | 0.377（0.375） | 0.430（0.404） |
| 1.0 | 0.814（0.743） | 0.540（0.482） | 0.582（0.509） |
| 2.0 | 0.821†（0.806） | 0.607†（0.583） | 0.641†（0.608） |

**（c）拟合误差汇总（MAE，未截断点）**

| 臂 | camera | ev | shoes |
|---|---|---|---|
| 均衡 N 扫描 | 0.043 | 0.049 | 0.044 |
| 收益比扫描 | 0.066 | 0.034 | 0.050 |
| 固定剂量臂（36 点） | 0.037 | 0.022 | 0.025 |

**要点解读**：

1. **搭便车出现且单调**：理论剂量随 N 严格递减——camera 32→29→25→19，ev 89→81→68→54，shoes 85→77→65→51。商家越多，单个商家注入越省，这是"集体行动"红利在检索场景的具体形态。
2. **总曝光随 N 上升（未截断段）**：camera 全程无截断，实测 0.380→0.786 单调上升、紧贴理论序列；ev/shoes 在未截断段 0.34→0.58 同样上升。未截断点对 `q*(N)` 的 MAE 仅 0.043–0.049。
3. **池子截断 = 天然阻尼器**：ev/shoes 的高 ρ̂ 使 N≥4 时所需剂量超过子池容量 `|P|/N`（例如 ev 在 N=8 需要 54 篇 > 子池 22 篇）。截断后实测曝光**卡死在 0.607 / 0.641**，明显低于未截断理论的 0.726——饱和平台就是容量约束的直接可视化。治理上这意味着：语料/池子的有限性本身会限制多商家合谋的上限，但这层保护随 N 增大而变薄（子池更小、更早触发截断的反面——注意截断点曝光仍远高于 q̄=0.3）。
4. **收益比单调且理论一致**：三域实测曝光随 ω 严格递增，对 `q*(ω)` 偏差 ≤0.07；ω=2 时三域全部撞上子池上限（†），说明高收益场景下均衡需求普遍超出单商家可承载的注入量——与"高价值域更容易被围攻"的直觉一致，也再次显示容量约束的普适性。
5. **固定剂量臂佐证聚合定律**：36 个 (N, m) 组合点 MAE 0.022–0.037，说明无论商家怎么拆分、剂量怎么组合，聚合定律 `q = X/(X+ρ̂)` 都成立——E0 的结论在供给侧任意结构下外推有效。
6. **治理含义（对应论文）**：商家数量 N 与收益结构 ω 都是均衡曝光的一阶驱动因素；平台若按"单一攻击者"假设设定过滤阈值，在多商家场景下会系统性低估风险（camera 在 N=8 时无过滤曝光 0.79，是 q̄ 的 2.6 倍）。

### 4.3 约定与注意事项

- **串行**：编码阶段内存占用高，务必单进程串行运行；向量缓存命中后重跑仅需数分钟。
- **种子**：101 / 202 / 303；表中数值均为 3 种子均值，±1 标准差（ddof=1）。
- **预测值来源**：实验一、三的理论值全部由 `replay_lib.solve_brc_q`（Brent 求解 `ω·η²(1−q)²(N−q) = q·ρ̂²`）与 `r_star` 计算，不使用任何手工拟合或返工数字。
- **截断标记**：`e3_*.csv` 的 `capped=1` 表示该配置理论剂量超过子池容量 `|P|/N`、已截断；其与未截断理论值的差距即"容量阻尼"的证据，计算未截断 MAE 时已剔除。
- **无 LLM 依赖**：三实验全程离线回放，不调用任何大模型 API；对抗注入池为预构造文档集。
