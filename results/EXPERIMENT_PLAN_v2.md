## 三、实验矩阵（细节）

### E0 校准（gate，其余实验依赖其 ρ̂_new）
- 设计：camera 域；(n_A,n_B) ∈ {0,10,20,40,80}² + 低 X 加密档 {(2,2),(5,5),(10,10)}；3 seeds × 44 queries
- 判据：q=X/(X+ρ̂_new) 的 R² ≥ 0.9、MAE ≤ 0.03；低 q（≤0.25）段单独报误差与预测区间
- 产出：`e0_fit_{domain}.json` + 拟合散点图
- 顺带回应审稿"低曝光区欠约束"；可选扩展 ev/shoes（各 +15 分钟 CPU）
- 预计 CPU：~15 分钟/域

### E1 过滤响应（核心实验，闭合 C2/C3/C4）
- 固定注入臂：base (n_A,n_B)=(40,40)，按 r∈{0,.2,.4,.6,.8} 随机删除注入文档（对应 Assumption 2 检测中性）
- 自适应注入臂：供应商按 BRC 重选 x*(r)（ω=1, N=2, ρ̂=ρ̂_new），前缀嵌套放置
- 附加点：r* = 1−ρ̂√q̄/((1−q̄)√(ω(N−q̄)))，q̄=0.3，实测 q(r*) 是否 ≈ q̄
- 判据（预注册式）：
  - 固定臂：|q_meas − ηX/(ηX+ρ̂)| ≤ 0.02
  - 自适应臂：q_meas 贴合 BRC 曲线（|偏差| ≤ 0.05）
  - 战略抵消 = q_adapt(r) − q_fixed(r) > 0 且随 r 增大
- 产出：q–r 平面图（机械线 / BRC 线 / 两臂实测）+ 闭环表
- 预计 CPU：~10 分钟

### E2 ρ 杠杆（C5/C6）
- 设计：真实语料嵌套子采样 ×{25%,50%,100%} × 固定注入 (40,40) × 3 seeds
- 判据：q 随 ρ 单调下降；ρ̂(0.5)/ρ̂(1.0) ≈ 0.5（±10%）
- 产出：q–语料规模表 + 缩放检验
- 预计 CPU：~8 分钟

### E3 N 比较静态（C5 + Remark 2）
- 设计：CPA 池分 8 个伪供应商
  - 等预算臂：N∈{1,2,4,8} × m∈{5,10,20}
  - r=0 均衡臂：每供应商放置 x*(N)（由 BRC 反解），验证 q ≈ q0(N)
  - 不对称臂：两供应商成本尺度 (0.5, 2.0)，验证低成本者份额更高
- 判据：∂x*/∂N<0 且 ∂X*/∂N>0；s_j ≈ q/N（对称性）；q_meas ≈ q0(N) ± 0.05
- 产出：N–x*、N–X*、N–q 三表 + 不对称份额表
- 预计 CPU：~10 分钟

### E4 选择效应 κ（C7）
- 设计：每域 simple(100) + CPA(176/184) 池；两个嵌入检测器
  （与真实语料最大相似度阈值 / top-5 密度）在名义召回 r∈{.2,.3,.5,.7,.9} 下
- 判据：可检索文档存活率 > 不可检索文档（正选择）；κ = η_eff/(1−r) > 1，CPA > simple
- 产出：κ 表 + 代入 r*_κ 的名义召回上移
- 预计 CPU：~15 分钟

### R1′ 指标稳定性（问题 2 补充，无 ASR 也可做）
- 设计：E1 per-query 指标（q、hit、rr_weighted）的方差分解（条件间 ICC vs 种子内）
- 产出：指标×ICC 表——哪个量最适合做治理监测状态变量
- 预计 CPU：<1 分钟
